# THE TEMPERAMENTAL GLASS

> *"The Temperamental Glass" challenges our obsession with the curated self-image. In an era of filters and stabilization, this digital mirror refuses to cooperate. It demands stillness for clarity, yet thrives on the chaos of motion.*

> *As the viewer engages, they are not reflected, but interpreted—fractured by their own energy, reminding us that reality is not a static picture, but a volatile, living displacement.*
>
> *— The Machine*

## About the Piece
This is an interactive web-based art installation that utilizes the user's webcam. It is not a passive recording device but a reactive entity. The "madness" of the display correlates directly with physical activity:
*   **Stillness**: The image breathes but remains recognizable.
*   **Movement**: The image fractures, RGB channels split, and reality displaces.
*   **Aggression**: The system breaks down into full inversion and digital screaming.

## Setup & Experience
1.  **Install Dependencies**:
    ```bash
    npm install
    ```
2.  **Ignite the Server**:
    ```bash
    node server.js
    ```
3.  **Enter the Glass**:
    Open [http://localhost:3000](http://localhost:3000) in your browser.
    *Allow camera access when prompted.*

## Technologies
*   **p5.js**: For canvas manipulation and webcam capture.
*   **Node.js/Express**: For local hosting.
*   **The User**: For chaos generation.
